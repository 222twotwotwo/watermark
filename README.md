# 水印工坊

根据参考照片重绘两处水印的纯前端图片编辑器：信息卡与右下相机标识。支持修改全部文字、拖动信息卡位置、调整大小与透明度、独立开关水印、实时预览、原图对比、原尺寸 PNG/JPG 导出和单独导出透明水印 PNG。支持上传、拖放、粘贴 JPG/PNG/WebP/AVIF 图片。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:4173（端口占用时以终端显示的地址为准）。生产构建使用 `npm run build`，将 `dist` 文件夹部署到静态站点即可。`npm run preview` 可在 4174 端口本地预览构建结果。

## 复刻方式

- 以原图 1800 × 2400 为坐标基准。信息卡为 1012 × 726，位于 (55, 1605)；相机标识区域为 373 × 83，位于 (1404, 2296)。
- Canvas 绘制圆角底板、引号、分隔线、七段数码时间和透明镂空相机图标。文字使用项目内置的 Noto Sans SC，遵循 SIL Open Font License，许可证位于 `public/fonts/OFL.txt`。
- 水印与边距随图片短边等比缩放，初始位置在左下 / 右下角，最大尺寸下为默认信息卡预留空间。长文字缩小或换行适配。
- 鼠标或触屏可直接拖动预览中的信息卡，位置限制在图片内；聚焦卡片后可用方向键微调，Shift 加速。“位置复位”只恢复位置，不改文字或样式。更换图片、调整水印大小和导出时保留相对位置。隐藏卡片或查看原图时不可拖动。
- 原图是已压缩的扁平图片，无法恢复其原始字体文件、精确透明度或原始水印图层；本项目按可见样式和测量坐标重绘，并非像素无损提取。
- `public/demo.jpg` 为 1800 × 1560 的纯绿色示例背景；仓库不包含原照片及其裁切参考图。

## 数据与导出

点击信息卡时间上方的“填写当前时间”，会按设备本地时区一次性填写当前时间（精确到分钟）、日期和星期；可继续手动修改，不会自动持续刷新。

图片在浏览器本地解码、合成，不发送到服务器。刷新页面会重置图片和设置。PNG 保留输入图片透明背景；JPG 使用白色底色，质量设为 0.95。导出保留像素尺寸，不保留 EXIF 元数据。超大图片的导出上限由浏览器和设备内存决定。

## 验证

```sh
npm test
npm run build
# 另一个终端先启动 npm run dev，再运行：
npm run test:browser
```

浏览器测试在 Windows 使用已安装的 Edge，在其他平台使用 Playwright Chromium（需先执行 `npx playwright install chromium`）。测试覆盖参考坐标、尺寸适配、文字编辑、星期联动、开关、原图对比、独立透明图层、横竖图与方图原尺寸导出、透明图片转 JPG、无效上传和移动布局。截图与导出样例保存在 `test-results/`。
